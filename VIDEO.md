# Видео с мероприятия

Блок «Как это проходит» на главной. Пока ссылки нет — блок не показывается.

## Как добавить

**1. Залейте ролик на YouTube.** Доступ можно поставить
«Доступ по ссылке» — в поиске YouTube он не появится,
а на сайте будет работать.

**2. Скопируйте адрес** из адресной строки.

**3. Вставьте в `content.js`:**

```js
video: {
  id: "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
  title: "Как это проходит",
  subtitle: "Один вечер в «Гаухартас» — от встречи гостей до последнего танца.",
  poster: "assets/ph-big-main-1700.webp",
  caption: "Ұзату той на 180 гостей, июль 2026"
}
```

Принимается любой формат: полная ссылка, `youtu.be/...`, `shorts/...`,
ссылка с меткой времени или просто ID из 11 знаков.

**4. Выкатите:** `git pull && sudo bash deploy/aws/update.sh`

## Почему так, а не обычная вставка

Стандартный код YouTube тянет около мегабайта скриптов и ставит куки
**на каждой загрузке страницы** — даже если видео никто не включил.
Для сайта, куда идёт платный трафик, это прямая потеря.

Здесь до нажатия показывается только обложка. Плеер создаётся
в момент клика, домен `youtube-nocookie.com` — без рекламных кук.

## Обложка

По умолчанию берётся фото большого зала. Превью самого YouTube
использовать не стоит — оно мутное и часто с неудачным кадром.

Хотите свой кадр: положите файл в `assets/` и укажите путь в `poster`.
Нужен горизонтальный, 16:9, шириной от 1600 px.

## Подпись

```js
caption: "Ұзату той на 180 гостей, июль 2026"
```

Конкретика работает лучше прилагательных: «180 гостей» человек
примеряет на себя, «незабываемая атмосфера» пролистывает.

Пусто — строки под видео не будет.

## Убрать блок

```js
video: { id: "" }
```

## Просмотры считаются

Нажатие уходит событием `video_play` в GA4, Google Ads и Метрику
(если идентификаторы заполнены). Видно, сколько человек включили ролик.
