# Малый зал «Гаухартас» — промо-страница

Автономная одностраничная сборка. Ничего от основного сайта не требует.

## Запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Файлы `index.html` и `assets/` кладутся куда угодно — например
в `/var/www/gaukhartas/small/`, тогда адрес будет `gaukhartas.com/small/`.

## Сцены

| | Что происходит |
|---|---|
| **1. Фасад** | Заголовок собирается по буквам, камера медленно наезжает на здание |
| **2. Порог** | Створки расходятся, интерьер выезжает навстречу — «вход внутрь» |
| **3. Обзор 360°** | 8 ракурсов на 3D-цилиндре. Тянется мышью и пальцем, крутится скроллом, есть стрелки и клавиатура. Инерция и автовращение с паузой после жеста |
| **4. Слайды** | Горизонтальная лента: лаунж, фотозона, сервировка |
| **5–6. Цифры и контакты** | |

## Фотографии

В работу взяты **только кадры малого зала**: светлое помещение с
панорамными окнами, диваном и фотозоной, плюс нейтральные детали
сервировки. Кадры большого зала (колонны, трон, экран с логотипом)
не используются нигде — это проверяется автотестом.

Каждое фото собрано в трёх размерах (640 / 1080 / 1700 px, WebP) и
подключено через `srcset`. Со 108 МБ исходников до 2.9 МБ.

Заменить фото: положить новый файл в `assets/` в трёх размерах с тем же
именем и поправить массив `VIEWS` в конце `index.html`.

## Если что-то не грузится

Страница рассчитана на отказ CDN: без GSAP она остаётся полностью
рабочей — панорама крутится, блоки видны, ссылки кликаются. Прелоадер
не висит дольше 6 секунд ни при каких условиях.

При `prefers-reduced-motion` тяжёлые анимации отключаются.
