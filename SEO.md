# Индексация в Google и Яндексе

## Что уже настроено на сайте

| | |
|---|---|
| `robots.txt` | открыт весь сайт, закрыты `/admin/`, `/app/`, `/deploy/` |
| `sitemap.xml` | 2 страницы: главная и малый зал, с датами и картинками |
| `canonical` | на обеих страницах — не будет дублей |
| `hreflang` | ru-KZ, kk-KZ, x-default |
| Микроразметка | `Restaurant + EventVenue + FAQPage` на главной, `EventVenue` на малом зале |
| Гео-метки | координаты, `KZ-AST` |
| Open Graph | превью в WhatsApp и Instagram |
| IndexNow | ключ на сайте, автопинг Яндекса и Bing после каждого обновления |

**Чего нет и без вас не появится: подтверждения прав.** Его нельзя
сделать за вас — нужен вход в ваш Google и Яндекс аккаунт.

## Шаг 1. Google Search Console (15 минут)

1. Откройте <https://search.google.com/search-console>
2. **Добавить ресурс** → выберите **«Ресурс с префиксом URL»**,
   впишите `https://gaukhartas.com`
3. Способ подтверждения — **HTML-тег**. Скопируйте оттуда `content="…"`
4. В `index.html` найдите строку и раскомментируйте, вставив свой код:
   ```html
   <meta name="google-site-verification" content="СЮДА_КОД_GOOGLE">
   ```
   То же самое в `small/index.html`
5. `git push` → `sudo bash deploy/aws/update.sh`
6. Вернитесь в Search Console → **Подтвердить**
7. Слева **Файлы Sitemap** → добавить `sitemap.xml` → Отправить
8. **Проверка URL** → вставьте `https://gaukhartas.com/` →
   **Запросить индексирование**. Повторите для `/small/`

## Шаг 2. Яндекс.Вебмастер (15 минут)

1. Откройте <https://webmaster.yandex.ru>
2. **Добавить сайт** → `https://gaukhartas.com`
3. Подтверждение — **Мета-тег**. Скопируйте код
4. Раскомментируйте в обоих файлах:
   ```html
   <meta name="yandex-verification" content="СЮДА_КОД_ЯНДЕКСА">
   ```
5. Выкатите, нажмите **Проверить**
6. **Индексирование → Файлы Sitemap** → добавить
   `https://gaukhartas.com/sitemap.xml`
7. **Индексирование → Переобход страниц** → добавить обе ссылки
8. **Информация о сайте → Регион** → укажите **Астана**.
   Для местного поиска это важнее всего остального на этой странице

## Шаг 3. Карточки организации — важнее сайта

По названию заведения карточка в картах показывается **выше** сайта.

* **Google Business Profile** — <https://business.google.com>.
  Заведите, подтвердите по почте или телефону, залейте фото и часы
* **Яндекс.Бизнес** — <https://yandex.ru/sprav>. В Казахстане Яндекс.Карты
  смотрят часто, карточка бесплатная
* **2ГИС** — карточка есть (4.6, 4532 оценки). Проверьте, что в ней
  стоит ссылка на сайт: это и трафик, и сигнал поиску

## Шаг 4. Автопинг

После каждого обновления `update.sh` сам сообщает Яндексу и Bing:

```bash
sudo bash deploy/aws/update.sh     # внутри вызовет indexnow.sh
bash deploy/aws/indexnow.sh        # или вручную
```

Google IndexNow не поддерживает — для него только Search Console.

## ⚠️ Про запрос «gaukhartas»

Название **не свободно**. По нему уже выдаются: казахстанская
женская группа «Гаухартас», фильм Казахфильма 1975 года, квартира
в Алматы, люди с таким именем.

Значит, целиться надо не в «gaukhartas», а в **«гаухартас астана»**,
**«гаухартас банкетный зал»**, **«гаухартас той хана»** — там вы
будете первыми. И тем важнее карточки в картах: по ним заведение
находят по названию + городу.
