# Большой зал «Гаухартас» — промо-страница

Автономная одностраничная сборка, сделана по той же схеме, что и `/small/`.
Ничего от основного сайта не требует.

## Запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Файлы `index.html` и `assets/` кладутся в `/var/www/gaukhartas/big/`,
адрес будет `gaukhartas.com/big/`.

## Сцены

| | Что происходит |
|---|---|
| **1. Фасад** | Заголовок «Большой зал» собирается по буквам, камера наезжает на здание |
| **2. Порог** | Створки расходятся, зал выезжает навстречу — «вход внутрь» |
| **3. Обзор 360°** | 11 ракурсов на 3D-цилиндре. Тянется мышью и пальцем, крутится скроллом, есть стрелки и клавиатура. Инерция и автовращение с паузой после жеста |
| **4. Слайды** | Горизонтальная лента: сцена, убранство, дастархан, сервировка |
| **5–6. Цифры и контакты** | до 350 гостей, сцена и LED-экран, танцпол, 10:00—02:00 |

## Фотографии

15 кадров из съёмки большого зала: зал целиком, центральный проход,
сцена с LED-экраном, президиум, свет во время тоя, рассадка, национальный
дастархан, сервировка, лестница в холле. Экстерьер взят тот же, что на
странице малого зала (`exterior-*.webp`).

Каждое фото собрано в трёх размерах (640 / 1080 / 1700 px, WebP) и
подключено через `srcset`. Со 132 МБ исходников до 5.8 МБ.

**Не вошли три кадра** — на них читаются имена гостей и план рассадки
конкретного тоя (`IMG_8398`, `IMG_8366`, `IMG_8399`). Публиковать их без
согласия людей со снимков не стоит.

Заменить фото: положить новый файл в `assets/` в трёх размерах с тем же
именем и поправить массив `VIEWS` в конце `index.html`.

## Если что-то не грузится

Страница рассчитана на отказ CDN: без GSAP она остаётся полностью
рабочей — панорама крутится, блоки видны, ссылки кликаются. Прелоадер
не висит дольше 6 секунд ни при каких условиях.

При `prefers-reduced-motion` тяжёлые анимации отключаются.

## Что изменилось в основном сайте

* ссылки на `/big/` — в шапке, «бургере», карточке большого зала и подвале;

  `index.html`, казахские строки в `lang.js`);

* в шапке ссылки на страницы залов прячутся уже с 1200 px — семь пунктов
  меню не помещались рядом с кнопкой брони.
