## 📁 СТРУКТУРА ПРОЕКТА

```text
gaukhartas/
├── index.html          # Главная страница (Hero, 3D залы, Калькулятор сметы, Отзывы 4.9, Контакты)
├── content.js          # Конфиг данных (Цены меню, тексты, рейтинг 2ГИС, FAQ, таймлайн)
├── engine.js           # Движок сайта (калькулятор сметы, сбор заявок, воронка аналитики)
├── lang.js             # Двуязычие (Русский / Қазақша)
├── base.css            # Основные стили оформления
│
├── big/                # Отдельный лендинг Большого зала (до 300 гостей)
│   └── index.html
├── small/              # Отдельный лендинг Малого зала (до 160 гостей)
│   └── index.html
│
├── admin/              # Веб-панель управления администратора
│   ├── index.html
│   └── admin.js
├── app/                # PWA-приложение для телефона (установка на главный экран)
│   ├── index.html
│   ├── app.js
│   └── manifest.json
│
├── assets/             # Все фото, 3D логотипы, фавиконы, видео-постеры
├── print/              # Полиграфия для печати (PDF-палатки на столы)
├── deploy/             # Серверная часть
│   ├── server.js       # Node.js API бэкенд (Express, авторизация, запись лидов)
│   ├── nginx.conf      # Конфиг веб-сервера Nginx
│   └── aws/update.sh   # Скрипт автоматического обновления на сервере
│
├── tests/              # 11 авто-тестов (проверка валидации, форм, UTM-меток)
└── build.sh            # Сборщик релизной версии deploy/public с защитой кэша
```
