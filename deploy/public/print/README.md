# Печатные материалы

## Настольная палатка с QR

```bash
python3 make_tent.py
```

Три файла:

| Файл | Что это |
|---|---|
| `tent-print.pdf` | A4 альбомная, 300 dpi — нести в типографию |
| `tent-preview.png` | как выглядит |
| `qr-only.png` | только QR — для наклеек, визиток, экрана |

## Как печатать

**Бумага:** плотный картон 300 г/м², матовая ламинация.
Глянец бликует под люстрами, и камера не поймает код.

**Печать:** A4, альбомная ориентация, **без масштабирования**
(«100%», не «по размеру страницы» — иначе поедут пропорции QR).

**Сборка:** согнуть пополам по пунктиру. Получится палатка
148×210 мм — стоит сама, читается с обеих сторон.

Одна сторона по-русски, вторая по-казахски: за столом сидят
и те, и другие.

**Тираж:** по числу столов + 20% запаса. Для 300 гостей это
25—30 столов, значит 35 штук.

## Куда ставить

| Место | Зачем |
|---|---|
| Центр каждого стола, рядом с композицией | основное |
| Стойка администратора | пока ждут |
| У выхода из зала | последнее, что видят |
| Фотозона | там достают телефоны |
| Туалетные комнаты, у зеркала | звучит странно, работает лучше всего |

**Не ставить:** рядом со свечами и у края стола.

## Проверка перед тиражом

Распечатай **один** экземпляр и отсканируй тремя телефонами
с расстояния вытянутой руки. Открылся WhatsApp с текстом
«Свободные даты? [QR]» — можно печатать тираж.

## Почему текст такой короткий

Кириллица в ссылке кодируется вдевятеро: «З» превращается
в `%D0%97`. Длинная фраза давала QR 77×77 модулей — камера
такой не читает. Короткая — 53 модуля, читается уверенно.

Проверено декодером в трёх масштабах.

## Метка [QR]

Она попадает в первое сообщение клиента. Менеджер видит код
и при создании брони выбирает источник «Пришли сами».

Так в отчёте по каналам будет видно, сколько броней принесли
палатки на столах.

## Сменить телефон или текст

В начале `make_tent.py`:

```python
PHONE = "77760077725"
CODE  = "QR"
```

После правки перезапустить скрипт. **Обязательно проверь
читаемость**, если удлинишь текст.
