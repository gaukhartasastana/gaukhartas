# Тесты

```bash
cd tests && for t in test*.js; do node "$t"; done
```

| Файл | Что проверяет |
|---|---|
| `test.js`  | движок: данные, калькулятор, форма |
| `test2.js` | боевая страница, язык, валидация админки, вес |
| `test3.js` | привязка данных к вёрстке, переводы, SEO |
| `test4.js` | смысл перевода, язык на телефоне, жесты книги |
| `test5.js` | калькулятор рейтинга 2ГИС |

Нужен `jsdom`: `npm i jsdom`
