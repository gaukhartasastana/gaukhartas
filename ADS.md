# Google Ads: что настроить, чтобы бюджет не горел

## Что было не так

Реклама уже крутится, а на сайте не было:

* **формы заявки** — только WhatsApp и звонок. Кто не готов писать
  в мессенджер, уходил молча
* **отслеживания конверсий** — Google Ads не знал, какой клик принёс
  клиента, и оптимизировал под клики
* **пропуска заставки** — человек с объявления упирался в экран
  «Нажмите, чтобы войти» с заблокированным скроллом на 5,25 секунды

Всё три закрыто.

## Шаг 1. Вставить свои идентификаторы

В `index.html` найдите блок `window.GH_ADS` и заполните:

```js
window.GH_ADS = {
  gaId:  'G-XXXXXXXXXX',      // GA4
  adsId: 'AW-XXXXXXXXX',      // Google Ads
  labels: {
    lead:     'AbCdEfGhIjK',  // ярлык конверсии «заявка»
    whatsapp: '...',          // «клик по WhatsApp»
    call:     '...'           // «клик по телефону»
  },
  ymId: '12345678'            // Яндекс.Метрика, только цифры
};
```

Пока поля пустые, скрипты не подгружаются — страница не тормозит.

**Где взять ярлыки:** Google Ads → Цели → Конверсии → создать три
конверсии → у каждой «Настроить тег» → там `send_to: AW-.../ЯРЛЫК`.
Нужна часть после косой черты.

## Шаг 2. Три конверсии в Ads

| Название | Событие | Ценность |
|---|---|---|
| Заявка с формы | `lead_submit` | основная, ставьте её основной |
| Клик в WhatsApp | `whatsapp_click` | второстепенная |
| Клик по телефону | `call_click` | второстепенная |

Основной в аккаунте сделайте **только заявку**. Иначе Google начнёт
гнать людей, которые кликают на телефон и не звонят.

## Шаг 3. Проверить, что считается

После выкладки откройте сайт с `?gclid=test123`, отправьте заявку
и посмотрите в Ads → Инструменты → Диагностика тегов. Конверсия
появляется в отчётах с задержкой до 3 часов — это нормально.

## Куда вести объявления

| Кампания | Ссылка |
|---|---|
| Свадьбы, той, большие торжества | `https://gaukhartas.com/#apply` |
| Мерейтой, сүндет той, 1 жас | `https://gaukhartas.com/small/` |

Ссылка с `#apply` открывает страницу сразу на форме.

## Что ещё режет конверсию

* **Отдел продаж до 21:00.** Реклама крутится круглосуточно, а
  ночные заявки ждут утра. Либо ограничьте показы по времени,
  либо поставьте автоответ
* **Нет отзывов на сайте.** У вас 4532 оценки на 2ГИС — самая
  сильная карта, и её не видно на сайте
* **Нет цены за зал целиком.** «От 13 500 ₸ на гостя» человек
  умножает сам и пугается. Покажите «банкет на 150 гостей — от X ₸»

## Уведомления в Telegram

Заявка приходит менеджеру за секунды:

```bash
sudo nano /etc/gaukhartas.env
# добавить:
TG_TOKEN=123456:AAH...      # от @BotFather
TG_CHAT=-1001234567890      # id группы менеджеров
sudo systemctl restart gaukhartas
```

Не задано — заявки просто копятся в админке, как раньше.

**Как получить `TG_CHAT`:** создайте группу, добавьте туда бота,
напишите в неё любое сообщение, откройте
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` — там будет `"chat":{"id":-100...}`.
