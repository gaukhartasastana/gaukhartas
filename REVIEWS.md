# Отзывы на сайте

## Что показывается сейчас

Только **проверяемые цифры с 2ГИС**: рейтинг 4.6, 4532 оценки,
2110 отзывов, 196 фото. Нажатие на цифру открывает карточку —
любой может сверить за пять секунд.

Текстовых отзывов **нет намеренно**. Выдумать их я не могу и вам
не советую: 2ГИС и Google находят фейки, а карточку за это могут
понизить или скрыть. Плюс гости узнают, что отзыв не их.

## Как добавить настоящие

`content.js`, массив `reviews`:

```js
reviews: [
  {
    name: "Айгуль",
    text: "Отмечали ұзату той на 180 гостей. Всё было готово...",
    date: "2026-06",
    rating: 5,
    source: "2gis",
    event: "Ұзату той"
  }
]
```

**Откуда брать:** скопировать реальные с карточки 2ГИС. Это законно —
отзыв публичный. Указывайте имя как в источнике и не правьте текст,
максимум сокращайте с многоточием.

Три-четыре отзыва достаточно. Больше — человек не читает.

## Обновлять цифры раз в квартал

`content.js` → `reviewsMeta`:

```js
rating: 4.6,
ratingsCount: 4532,
reviewsCount: 2110,
photosCount: 196,
```

Свежие цифры убедительнее круглых. Врать нельзя — проверяется
за пять секунд.

## Строка про преимущество

```js
edge: "Больше оценок, чем у любого банкетного зала Астаны"
```

Проверено 29.07.2026: у ближайшего конкурента 1114 оценок.
**Если перестанет быть правдой — уберите.** Ложное утверждение
на сайте дороже, чем отсутствие строки.

## Скрыть блок целиком

```js
reviewsMeta: { show: false }
```

Блок пропадёт. Также он прячется сам, если нет ни цифр, ни отзывов —
пустой заголовок хуже, чем ничего.

# Плавающая кнопка WhatsApp

Появляется, когда первый экран уехал вверх. Прячется у контактов
и у формы — там свои кнопки, две подряд выглядят навязчиво.

Один раз сама разворачивается с подписью «Спросить про дату»,
чтобы человек понял назначение, потом сворачивается в кружок.
Дальше раскрывается по наведению.

Метку канала подставляет движок: в первом сообщении будет код
источника, по нему менеджер поймёт, откуда пришёл человек.

При `prefers-reduced-motion` пульсация отключается.
